# JuCoding V4 content refinements

## Beginner-first priorities

1. Teach relationships before terminology.
2. Use one concrete example per concept.
3. Keep details that change often out of the canonical deck.
4. End with a safety boundary and human approval rule.

## Suggested 3-hour flow

1. Why vibe coding + AI vs Agent
2. Frontend / Backend / API / Database + GUI/TUI/CLI
3. Project planning terms
4. Development server / deployment / Git / GitHub
5. Chat AI vs computer/terminal Agent
6. MCP / Worker / automation examples
7. Safety boundary + recap

## Timing note

Detailed DBML syntax, detailed Git commands, deployment-provider comparison, and subscription-plan comparison should stay outside the core 3-hour beginner session.
